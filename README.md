# Digital Menu Platform

A responsive web application designed to replace traditional paper restaurant menus with a dynamic, digital solution. Users can scan a QR code to view the menu instantly on their smartphones. This project was built to practice frontend development and cloud database integration.

## 🚀 Features
* **QR Code Access:** Scan a QR code to open the digital menu instantly.
* **Real-time Updates:** Menu changes (prices, availability) update instantly without reloading.
* **Responsive Design:** Optimized for mobile phones, tablets, and desktops.
* **Cloud-Powered:** Powered by a live database to manage food categories and items.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend/Database:** Firebase Realtime Database (or Firestore)

## 🧠 What I Learned
* How to connect a frontend user interface to a cloud database (**Firebase**).
* How to manage real-time data syncing for seamless user experiences.
* How to structure clean, semantic **HTML** and write responsive **CSS** layout styles.
* How to handle dynamic DOM manipulation using vanilla **JavaScript**.
